# Instrumentarium

Landing page for https://instrumentarium.jp/.

A responsive, bilingual introduction to Instruments for Transposition between Architecture and Music, with links to Corda and Neuma. Visual styling follows the instruments; icons are inline SVG, including a standing-wave animation that respects reduced-motion preferences.

## Publish

In Settings → Pages select Deploy from a branch → main → / (root). The CNAME file specifies instrumentarium.jp. Configure the apex DNS for GitHub Pages and enable Enforce HTTPS after certificate issuance.

No build is required. Google Fonts are optional; system font fallbacks are included.
